LIGA DE BASEBALL MEXICANA - Interfaz en Java
=============================================

ESTRUCTURA
----------
ProyectoBD/
  Main.java                      Arranca el programa
  usuarios_finales.sql           Tabla Usuario + columna ID_Usuario en todas las tablas
  ejecutar.sh                    Compila y abre el programa
  mysql-connector-j-26.7.0.jar   (el tuyo, cópialo aquí)
  conexion/
    Conexion.java                Conexión a MySQL (usuario APP_LIGA)
  modelo/
    Sesion.java                  Usuario final que inició sesión (login contra la tabla Usuario)
    Campo.java                   Describe una columna: tipo, si es llave, si es obligatoria...
    Opcion.java                  Elemento de una lista desplegable (llaves foráneas)
  vista/
    Estilo.java                  Colores, fuentes y botones
    PanelLogin.java              Pantalla de inicio de sesión
    VentanaPrincipal.java        Ventana, barra superior y menú lateral
    PanelTabla.java              Clase base: formulario, tabla, buscador y CRUD
    tablas/
      PanelEstado.java
      PanelPosicion.java
      PanelPatrocinador.java


PASO 1: PREPARAR LA BASE (una sola vez)
---------------------------------------
  cd ~/Downloads/ProyectoBD
  mysql -u root -p < usuarios_finales.sql

Crea la tabla Usuario con dos usuarios finales:
  admin / admin123
  luis  / luis123
y el usuario de MySQL APP_LIGA, que es con el que la aplicación se conecta por dentro.


PASO 2: EJECUTAR
----------------
  cd ~/Downloads/ProyectoBD
  sh ejecutar.sh

O a mano:
  javac -encoding UTF-8 -cp mysql-connector-j-26.7.0.jar -d out Main.java conexion/*.java modelo/*.java vista/*.java vista/tablas/*.java
  java -cp out:mysql-connector-j-26.7.0.jar Main

Si tu conector tiene otro nombre, cámbialo en ejecutar.sh y en .vscode/settings.json.


CÓMO AGREGAR OTRA TABLA (ejemplo: Ciudad)
-----------------------------------------
1. Crea vista/tablas/PanelCiudad.java:

   package vista.tablas;

   import modelo.Campo;
   import vista.PanelTabla;

   public class PanelCiudad extends PanelTabla {

       public PanelCiudad() {
           super("Ciudad", "ciudad", true, "Ciudades",
                   Campo.id("ID_Ciudad", "ID"),
                   Campo.foranea("ID_Estado", "Estado", "Estado", "Nombre_Estado"),
                   Campo.texto("Nombre_Ciudad", "Nombre de la ciudad", 20));
       }
   }

2. Regístrala en VentanaPrincipal.java, dentro de registrarSecciones():

   agregar("CATÁLOGOS", new PanelCiudad());

   (y su import: import vista.tablas.PanelCiudad;)

Tipos de campo disponibles:
  Campo.id(columna, etiqueta)                         llave AUTO_INCREMENT
  Campo.texto(columna, etiqueta, maximo)              VARCHAR
  Campo.entero(columna, etiqueta)                     INT
  Campo.decimal(columna, etiqueta)                    DECIMAL
  Campo.fecha(columna, etiqueta)                      DATE (AAAA-MM-DD)
  Campo.foranea(columna, etiqueta, tablaPadre, columnaQueSeMuestra)

Ajustes que se pueden agregar al final:
  .opcional()     el campo puede quedar vacío (NULL)
  .comoLlave()    forma parte de una llave primaria compuesta (Contrato, Carrera, Alineacion)

Ejemplo de llave compuesta (Contrato):
  Campo.foranea("ID_Equipo", "Equipo", "Equipo", "Nombre_Equipo").comoLlave(),
  Campo.foranea("ID_Patrocinador", "Patrocinador", "Patrocinador", "Nombre_Patrocinador").comoLlave(),
  Campo.fecha("Inicio_Contrato", "Inicio").opcional(),
  Campo.fecha("Fin_Contrato", "Fin").opcional()

La clase base se encarga sola de guardar en ID_Usuario quién hizo el movimiento.
