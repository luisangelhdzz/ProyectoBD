LIGA DE BASEBALL MEXICANA - Interfaz en Java
=============================================

ESTRUCTURA
----------
ProyectoBD/
  Main.java                      Arranca el programa
  usuarios_finales.sql           Tabla Usuario, columna ID_Usuario en todas las tablas y tabla Bitacora
  ejecutar.sh                    Compila y abre el programa
  mysql-connector-j-26.7.0.jar   (el tuyo, cópialo aquí)
  conexion/
    Conexion.java                Conexión a MySQL (usuario APP_LIGA)
  modelo/
    Sesion.java                  Usuario final que inició sesión (login contra la tabla Usuario)
    Bitacora.java                Anota en la tabla Bitacora quién hizo cada movimiento
  vista/
    PanelLogin.java              Pantalla de inicio de sesión
    VentanaPrincipal.java        Ventana, barra con el usuario y una pestaña por tabla
    tablas/
      PanelEstado.java           Tabla Estado: formulario, tabla, buscador, validaciones y CRUD


PASO 1: PREPARAR LA BASE (una sola vez)
---------------------------------------
  cd ~/Downloads/ProyectoBD
  mysql -u root -p < usuarios_finales.sql

Se puede volver a ejecutar sin problema: lo que ya existe no se vuelve a crear.
Si ya lo habías corrido antes, córrelo otra vez para que se cree la tabla Bitacora.

Crea la tabla Usuario con dos usuarios finales:
  admin / admin123
  luis  / luis123
la tabla Bitacora y el usuario de MySQL APP_LIGA, que es con el que la aplicación se conecta por dentro.


PASO 2: EJECUTAR
----------------
  cd ~/Downloads/ProyectoBD
  sh ejecutar.sh

O a mano:
  javac -encoding UTF-8 -cp mysql-connector-j-26.7.0.jar -d out Main.java conexion/*.java modelo/*.java vista/*.java vista/tablas/*.java
  java -cp out:mysql-connector-j-26.7.0.jar Main

Si tu conector tiene otro nombre, cámbialo en ejecutar.sh.


VALIDACIONES DE LA TABLA ESTADO
-------------------------------
  ID        Opcional al insertar (MySQL lo asigna). Si se escribe, debe ser un entero mayor que 0.
            No puede quedar vacío al actualizar ni repetirse.
  Nombre    Obligatorio, máximo 20 caracteres.
  Actualizar y Eliminar piden seleccionar antes un estado de la tabla.
  Eliminar pide confirmación y avisa si hay registros de otras tablas que dependen del estado.

Cada alta o cambio guarda en ID_Usuario quién hizo el movimiento.
Además, altas, cambios y bajas quedan anotados en la tabla Bitacora (usuario, acción y fecha),
así también se sabe quién eliminó un registro.


CÓMO AGREGAR OTRA TABLA (ejemplo: Posicion)
-------------------------------------------
1. Copia vista/tablas/PanelEstado.java como vista/tablas/PanelPosicion.java y cambia:
   - el nombre de la clase y del constructor
   - la tabla y las columnas en las consultas (Estado, ID_Estado, Nombre_Estado)
   - los textos de las etiquetas y de los mensajes
   - el nombre de la tabla en las llamadas a Bitacora.registrar("Estado", ...)

2. Regístrala en VentanaPrincipal.java, dentro de mostrarPrincipal():

   pestanas.addTab("Posiciones", new PanelPosicion());

   (y su import: import vista.tablas.PanelPosicion;)
